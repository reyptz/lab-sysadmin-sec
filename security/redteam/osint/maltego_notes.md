# Maltego Basics

## Entités utiles

- Domain
- IPv4 Address
- Netblock
- DNS Name
- URL
- Person
- Email Address
- Phone Number

## Transformations classiques

- Domain → DNS Name (To DNS Name [MX / NS / SOA])
- Domain → Netblock
- IPv4 Address → Netblock
- Person → Email Address
- Email → Social networks

## Flux d'investigation

1. Domain cible → énumération DNS.
2. DNS → IP → Netblock → ASN.
3. Personnes clés → emails → fuites.
